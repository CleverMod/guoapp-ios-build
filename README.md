## 央视频直播接入（v6.0 更新于 2026-10-05）

全站源版提供独立「直播」入口，64 个频道按央视、CGTN、剧场、卫视和其他分组；所有取流与清单刷新在设备端运行，不依赖 Python、Docker 或远程自建服务。

1. 将用户提供的频道表、JCE PidTimeShift、TEA cKey、bkliveinfo 和 v6.0 设备协议迁入独立 Go 模块。使用独立 HTTP client 和本机回环监听，观看会话在后台刷新直播清单；短效地址失效时重新取流，设备线路未就绪时回退至 JCE / bkliveinfo。
2. 清单由本机输出，普通线路分片供播放器直连 CDN，设备签名线路的分片与附属资源由同一端口流式转发；独立会话令牌、关闭释放及空闲清理。保留 HLS 必要标签，滚动维护媒体序列和对应资源签名。
3. 新增 Flutter 频道页和直播播放页，复用 Android ExoPlayer 与 Windows/iOS media_kit 内核；提供换台、暂停、回到直播、有限错误重试、全屏与遥控器操作。直播不启用点播的断点续播、进度拖动、下一集预加载、自动下一集及下载。
4. 只新增直播桥接 action；现有 11 个站源、源权限、点播解析、播放器及 `app_stream.go` 的处理逻辑不改。直播入口只在全站源版、当前用户解锁时显示，切换用户时停止直播。
5. 完成后集中执行格式、Go 编译和可用的 Dart 静态检查，并核对点播相关源码保持一致。按 AGENTS.md 暂停自动化测试与回归的约定，不执行完整测试或声称真机验收通过；更新开发快照版本、同步纯源码并生成 ZIP。

实施状态：已完成上述源码接入。默认红果版不显示直播入口，Go 核心同时拒绝直播取流；全站源版的已解锁用户可打开直播，现有站源权限配置保持原样。直播频道配置独立于原站源管理。

使用：点击手机底部导航「直播」（电脑和电视模式使用侧边导航）→ 按分组或名称选择频道。播放器提供上一台、下一台、频道列表和「回到直播」；暂停后继续会重新取流回到直播。控制栏正常播放 4 秒自动收起，轻点画面可显示或隐藏，鼠标移动或遥控导航可显示；选择频道或音量时保持显示。支持 PageUp / PageDown 换台、空格播放 / 暂停、Esc 退出全屏，以及电视遥控器方向键选择和确认；控制隐藏时第一次遥控确认只唤回控制栏。进入后台暂停，回到前台重新取流；用户切换或锁定后停止直播并释放会话。iOS 音量复用系统媒体音量通道，Windows / Android 使用原有内核音量接口。

来源：协议与频道配置迁移自用户提供的 `ysp-live.zip`；包内注明 JCE 来源为 [Sophomoresty/mediago](https://github.com/Sophomoresty/mediago)，频道表和 cKey 来源为 [akiralereal/iptv](https://github.com/akiralereal/iptv)。

边界：频道配置数量不等于全部频道可用；匿名输出按此包最高 1080p，不宣称 4K/8K。原包的延迟说明约 20 秒，实际取决于时移窗口与播放器缓冲。接口、区域和节目时段可能影响可用性。

### 网络与资源设置

管理员从「设置与备份 → 网络与资源」选择自动、直连或手动代理，手动地址支持 HTTP、HTTPS、SOCKS5 / SOCKS5h。代理地址默认遮蔽、不进入备份；设备内播放服务始终绕过代理。自动模式读取系统静态代理与排除列表，恢复前台及每 30 秒更新；代理不会关闭 TLS 校验。

### 局域网互联：追剧同步与推送播放（已接入，待验证）

入口：「追剧 → 标题栏同步」或「设置与备份 → 设备互联」。手动同步默认「双向合并」，可选覆盖对方 / 覆盖本机，先「查看预览」再执行；自动同步仅发送改动条目与删除标记，播放期间约每 10 秒发送进度。冲突记录保留候选，用户从同步页逐项处理。

## 开发与构建


### 构建内置黄果旧版共享会话

用户要求通用 IPA 内置同一访客会话时，macOS 构建使用 `python3 scripts/build_ios.py --all-sources --legacy-session /本机私有路径/huangguo-session.json --require-legacy-session`。输入必须是有效的会话文件，包含 `version`、`scope`、`deviceId` 和非空 `token`；旧 App 的普通配置备份或 IPA 本身不包含该文件。真实会话保存在源码树以外，不提交 Git，不纳入纯源码镜像和快照。

GitHub Actions 使用仓库 Secret `HUANGGUO_LEGACY_SESSION` 保存会话 JSON，再在 `Build unsigned iOS IPA` 中勾选 `embed_legacy_session`。缺少有效输入时构建停止；默认构建不内置共享会话。构建仅将会话注入原生二进制，不打印真实令牌、设备标识或编码后的构建参数。内置会话可被 IPA 接收者使用，令牌失效仍需重新登录；此方法没有修复源站拒绝新访客登录的 API `4007`。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `lib` | 页面、播放器、本地用户、FFI、下载和媒体处理 |
| `native/core`、`native/bridge` | 独立站源核心、缓存、下载、目录迁移及 C ABI |
| `android`、`windows`、`ios` | 平台工程与必要资源 |
| `assets/video_enhancement`、`packages/media_kit_libs_windows_video` | 增强 Shader 与许可、固定 Windows 媒体依赖插件 |
| `scripts`、`.github/workflows` | 构建、签名、验证、同步和版本快照 |
| `test`、`integration_test` | 自动化与设备回归 |

## 站源开发约定

站源是 Go 原生 provider（`native/core/provider_*.go`），不是运行期加载的 Python 源。新增站源需接入：`provider_huangguo.go`（常量 / 白名单 / `canonicalProviderSource` / `GetHuangguoChapters`）、`provider_media.go`（baseURL / host 反查 / 播放分派）、`app_categories.go`、`app_cover_metadata.go`、`app_runtime.go`（Config 字段 + 目录 / 搜索 / 详情分派 + 空页放行），并在 `lib/models.dart` 登记 `SourceSite`。

注意：Go RE2 正则**不支持 lookahead**。解析多线路播放列表时不能用 `(?=...)` 做分段，否则非捕获组会消耗下一段开头；应改用显式字符串截断（从容器标记之后查找下一段标记）。
